# AI 告警分析 — 页面草图

## 背景理解

**用户意图**：
- 当前告警列表（原始告警逐条展示）→ 改为 **AI 聚合后的 Incident 列表**
- 点「AI分析」按钮 → 跳转到一个 **告警分析详情页**（类似故障分析页 SRECopilotView）
- 详情页包含：聚合后的告警 + 原始告警明细 + AI根因分析

---

## 路由设计

```
现有：
  /alarm/current        → RealtimeView.vue（概览+原始告警列表）
  /alarm/events         → EventsView.vue（事件操作记录）
  /ops/incident/:id     → SRECopilotView.vue（故障分析，已有）

新增：
  /alarm/current        → 改为「聚合事件列表」（Incident View）
  /alarm/analysis/:id   → AlarmAnalysisView.vue（新增，告警分析详情）
  /alarm/events         → 保留，但内容改为 Incident 管理
```
