## Patch-02 🔴 P0：转发配置表格永空（JSON.parse 崩溃）

**文件**：`src/views/ops/logs/OperationLogConfig.vue`

**原因**：后端 `forward_content` 存的是原始逗号串 `"app-*,nginx-*"`，不是 JSON。`JSON.parse("app-*,nginx-*")` 抛异常，`map()` 中途崩溃，整表为空。

**定位**：在 `<script setup>` 中、`const loading = ref(false)` 之后，插入辅助函数；在 `onMounted` 的 `map()` 中替换调用。

**改前**（map 内）：
```js
logType: item.forward_content ? JSON.parse(item.forward_content).join(',') : '--',
```

**改后**：在 `<script setup>` 中（`const loading = ref(false)` 之后）新增：
```js
function parseForwardContent(raw) {
  if (!raw) return '--'
  try {
    const arr = JSON.parse(raw)
    return Array.isArray(arr) ? arr.join(',') : String(arr)
  } catch {
    return String(raw).split(',').join(',')
  }
}
```
map 内改为：
```js
logType: parseForwardContent(item.forward_content),
```

**验证**：访问 `/ops/logs/operation/config`，表格正常显示日志类型列（如 `app-*,nginx-*`），Console 无 SyntaxError。

```html
    </div>
    <div v-if="loading" ...>
```

script 部分需确保有以下 reactive/computed（若缺失需补）：
```js
const statusFilter = ref(null)

const filteredRecords = computed(() => {
  let list = records.value
  if (statusFilter.value) list = list.filter(r => r.status === statusFilter.value)
```
