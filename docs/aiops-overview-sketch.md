## 二、各模块详细样式

### 模块1：Hero Metric 行

```
┌─────────────────────────────────────────────────────────────────────┐
│  AI自动闭环数          │  告警降噪率               │  节省人工时      │
│                       │                           │                  │
│      3,452            │       91.5%               │      280         │
│     次/30天           │    100,000 → 8,500        │     小时         │
│                       │      (聚合后有效事件)       │                  │
│  [↑ 12% vs上月]      │  [↑ 5.2% vs上月]          │  [↑ 38h vs上月]  │
│                       │                           │                  │
└─────────────────────────────────────────────────────────────────────┘
```

**样式要点：**
- 3列均分布局，等宽
- 数字大字号（28px+），加粗
- 副标题灰色小字（12px）
- 环比箭头用颜色区分（↑绿涨/↓红跌）
- 背景浅蓝/渐变，与下方图表区分

**数据来源：**
- `GET /api/intelligent/ai-closed-alerts` → `{ count, trend, savedHours }`
- 或从 `realtimeAlerts` 前端计算（mock版）

## 三、布局网格规范

```
现有:
.stats-row { grid-template-columns: repeat(4, 1fr); }

改造后:
.hero-row  { grid-template-columns: repeat(3, 1fr); }  // Hero Metric
.row-2     { grid-template-columns: 1fr 1fr 1fr; }      // 模块3+4+2
.row-3     { grid-template-columns: 2fr 1fr; }          // 模块5(宽) + 备用
```

或使用 Ant Design `a-row` / `a-col`:
```
Hero: 3 × col-8
Row2: 3 × col-8
Row3: 2 × col-12 (或 3 × col-8 + 1 × col-8 合并)
```
