## 一、选中的两条告警（来自现有 mockData.js）

### 容量类：ID=2 — 磁盘空间不足
```js
{ id: 2, title: '磁盘空间不足', resource: 'db-primary (华东区域)',
  metric: '磁盘使用率', current_value: '92%', threshold: '> 90%',
  status: 'firing', duration: '12分钟',
  suggestion: '1. 清理过期日志文件\n2. 检查大表并归档历史数据\n3. 扩容磁盘或迁移数据' }
```
- **自动化可行性**：⭐⭐⭐⭐⭐ 高
- 清理临时文件/旧日志：脚本自动化，无风险
- 自动扩容云盘：API 调用，可回滚
- SOP 明确，风险低 → **AI 全流程接管**

### 证书类：ID=8 — SSL证书即将过期
```js
{ id: 8, title: '证书即将过期', resource: 'cdn-domain.example.com',
  metric: '证书剩余天数', current_value: '15天', threshold: '< 30天',
  status: 'firing', duration: '2.5小时',
  suggestion: '1. 申请新证书\n2. 更新证书配置\n3. 验证HTTPS访问正常' }
```
- **自动化可行性**：⭐⭐ 中
- AI 可提前 30 天发现 + 自动申请新证书（KMS API）
- 但推送到 LB/网关、灰度验证、回滚预案需要人工确认
- → **AI 半自动化：建议 + 人工审批**

## 四、对现有草图的改进分析

### 4.1 告警分析 Tab（列表页）改进

**当前草图问题 1：缺少「处理动作」列的区分**

当前草图操作列统一是「🤖分析 | 👁️查看」，但对容量类（可全自动）和证书类（需人工审批）应该有不同按钮：

```
改进前：
│ INC-0720 │ DB连接耗尽... │ 5 │🔴 │服务类│ 自愈中 │AI自动│🤖分析│👁️│
│ UNLINKED-2│ 磁盘空间不足  │ 1 │🔴 │容量类│ 告警中 │ —   │🤖分析│👁️│
│ UNLINKED-8│ SSL证书即将过期│1 │🟢 │证书类│ 告警中 │ —   │🤖分析│👁️│

改进后：
│ INC-0720 │ DB连接耗尽... │ 5 │🔴 │服务类│ 自愈中 │AI自动│🤖分析│👁️│
│ UNLINKED-2│ 磁盘空间不足  │ 1 │🔴 │容量类│ 告警中 │AI预检│⚡自愈│👁️│ ← 可直接自愈
│ UNLINKED-8│ SSL证书即将过期│1 │🟢 │证书类│ 待审批 │ 待审 │✅确认│👁️│ ← 需人工确认
```

新增「执行方式」列，区分：
- `AI预检`：AI 已分析，可直接自愈
- `待审批`：AI 已完成前置工作，等人工确认
- `人工处理`：AI 无法自动处理，需要人介入

### 4.3 整体布局改进

**当前草图问题 7：图表行的比例需要调整**

当前是 `1fr 1fr 1.5fr`，但降噪漏斗是纯 CSS 实现，可以做得更简洁。建议改为：
- TopN 分类：1fr（横向 Bar 列表）
- 降噪漏斗：0.8fr（简化为数字卡片）
- 处理趋势：1.7fr（面积图需要更多宽度）

或者将降噪漏斗移到 Hero 行旁边作为第 4 张 Hero 卡：

```
┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐ ┌─────────────────────┐
│  🤖 AI自动闭环数     │ │  📉 降噪率          │ │  ⚡ AI接管率         │ │  ⏱️ 节省人工时     │
│      3,452          │ │     91.5%           │ │      78.3%          │ │       280           │
│    次/30天          │ │  100K→8.5K          │ │  占总告警比例        │ │    小时/30天        │
│  [↑12%]             │ │  [↑5.2%]            │ │  [↑5.2pp]           │ │  [↑38h]             │
└─────────────────────┘ └─────────────────────┘ └─────────────────────┘ └─────────────────────┘
```

这样图表行可以只放 TopN + 趋势，布局更清晰。
