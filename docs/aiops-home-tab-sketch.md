## 四、操作列按钮规则

```
│ 状态    │ 类别    │ 操作列按钮                                    │
│---------│---------│---------------------------------------------│
│ 自愈中   │ 容量类   │ [⚡自愈] [👁️]                                │  ← 可直接执行
│ 告警中   │ 容量类   │ [⚡自愈] [👁️]                                │  ← 未开始自愈
│ 待审批   │ 证书类   │ [✅确认] [👁️]                                │  ← 需人工审批
│ 排查中   │ 阈值类   │ [🤖分析] [👁️]                                │  ← 需要AI分析
│ 已闭环   │ 任意类   │ [👁️]                                         │  ← 只读
│ 进行中   │ 任意类   │ [🤖分析] [👁️]                                │  ← 通用
```

## 五、路由变化

```
现有路由：
  /overview    → HomeView.vue  (homeTab='home')
  /aiops       → HomeView.vue  (homeTab='aiops')
  /alarm/*     → AlarmManageView.vue
  /ops/incident/:id → SRECopilotView.vue

  /alarm/analysis/:id → AlarmAnalysisView.vue  (详情全页，从列表「👁️」点击跳转)

HomeView.vue 内部变化：
  homeTab 增加 'alarm' 选项
  [告警分析] Tab 新增在 [AI运维] 前面
```

## 七、关键交互

```
用户进入首页 → 默认选中「告警分析」Tab
        │
        ├── 看 Hero 行：AI 闭环 3,452 次，降噪 91.5%
        │
        ├── 看图表行：容量类占 45%，趋势线 AI 上升人工下降
        │
        ├── 看列表 → 点某行操作列
        │     ├── [⚡自愈] → 触发自动修复流程（容量类）
        │     ├── [✅确认] → 触发证书推送审批（证书类）
        │     └── [👁️]    → router.push(`/alarm/analysis/${id}`) 打开详情
        │
        ├── 看应用卡片 → 点「分析」→ 跳转 AI运维 根因定位
        │
        └── 看修复记录 → 点「查看全部」→ 跳转 /alarm/current
```
