## 二、后端 Mock 数据变更

### 2.1 alerts 表新增字段

```sql
-- server/db/001_cmdb_schema.sql (新增)
ALTER TABLE alerts ADD COLUMN category        VARCHAR(32);  -- 7大类
ALTER TABLE alerts ADD COLUMN incident_id     VARCHAR(64);  -- 聚合事件ID
ALTER TABLE alerts ADD COLUMN ai_closed       BOOLEAN DEFAULT false;  -- AI自动闭环
ALTER TABLE alerts ADD COLUMN ai_closed_at    TIMESTAMPTZ;  -- AI闭环时间
ALTER TABLE alerts ADD COLUMN closed_by       VARCHAR(32) DEFAULT 'manual';  -- manual|ai
ALTER TABLE alerts ADD COLUMN suppression_reason VARCHAR(128);  -- 去重静默原因
```

### 2.2 新增 incidents 表（后端新建）

```sql
-- server/db/002_aiops_schema.sql (新建)
CREATE TABLE IF NOT EXISTS ai_incidents (
  id              SERIAL PRIMARY KEY,
  incident_no     VARCHAR(64) UNIQUE NOT NULL,  -- 如 INC-2026-001
  root_cause      VARCHAR(512),                  -- 根因描述
  affected_count  INT DEFAULT 1,                 -- 聚合告警数
  level           VARCHAR(32) NOT NULL,
  status          VARCHAR(32) DEFAULT 'open',    -- open|investigating|resolved|closed
  created_at      TIMESTAMPTZ DEFAULT NOW(),
  resolved_at     TIMESTAMPTZ,
  handler         VARCHAR(128)                   -- AI|人工
);
```
